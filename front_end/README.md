# E-Vaccine Reminder frontend

Install dependencies with `npm install`, then run `npm run dev`. The backend
defaults to `http://localhost:5000/api`; set `VITE_API_URL` in a local `.env`
file if it is hosted elsewhere. See the repository's `readme.txt` for complete
backend, database, email, and WhatsApp setup instructions.

Run `npm run lint` and `npm run build` to validate the frontend.
